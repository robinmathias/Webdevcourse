Homework #1 solution

Files:
- index.html
- addPost.html
- login.html
- style.css
- assets/

How to test:
1. Open index.html in a browser.
2. Hover Home/Add Post.
3. Click navigation links.
4. Check that index.html has 5 posts.
5. Open login.html and try submitting with empty fields: browser blocks submission.
6. Fill both fields and press Log in: it returns to index.html.
7. Open addPost.html and press Create post: it returns to index.html.
8. Use browser responsive/device mode to test phone layout.

Before submission:
- Put these files in your team GitHub repository.
- Every team member must make at least one commit.
- Enable GitHub Pages.
- Submit the required .txt file with team number, names, repository link, and deployed GitHub Pages link.
