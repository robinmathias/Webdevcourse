# Kodutöö 3

Eelmise kodutöö postituste leht Vue, Vuex ja Vue Routeriga.

Käivitamine:

```sh
npm install
npm run dev
```

Avalehel on 10 postitust. Like-nupp lisab ühe meeldimise ja Reset likes nullib kõik meeldimised. Signup-lehel kontrollitakse parooli tingimusi. Eduka kontrolli järel minnakse avalehele. Tegelikku kasutajakontot ei looda.
