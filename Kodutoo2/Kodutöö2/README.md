# PostIt

See on minu veebiarenduse teine kodutöö, kus täiendasin esimeses kodutöös tehtud PostIt veebilehte.

Seekord lisasin JavaScripti, et postitused tuleksid JSON-failist ja neid ei peaks enam käsitsi HTML-i kirjutama.

Lisaks saab postitusi laikida, uusi postitusi lisada ja profiilipildi peale vajutades avaneb väike menüü.

## Kasutatud

- HTML
- CSS
- JavaScript
- JSON

## Käivitamine

Ava projekt VS Code'is ja käivita `index.html` Live Serveriga.
