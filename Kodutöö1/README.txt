##Postlt

A simple social media website made for the Web Development course.

This is the second homework, based on the website created in Homework 1. The main difference is that posts are now loaded from a JSON file using JavaScript instead of being written directly in HTML.

The website also has a profile dropdown menu with user information and a logout option.

## Running the project

Open the project in VS Code and run `index.html` using Live Server.

Built with HTML, CSS and JavaScript.
